# WHAT THE SECOND CORPUS COST AND BOUGHT (2026-08-01).
#
# It reached 7/10 the day it arrived and 9/10 the same day, and every one of the
# four bugs between was an ENGINE bug that p5.js could not have found:
#
#   data: URLs could be written but never read - so Phaser's three base64 boot
#   textures all failed, and the framework waited forever with isBooted true and
#   isRunning false, reporting nothing
#
#   PNG did not decode without SDL, because it arrived through a hook only the
#   application layer installs and tests/ is SDL-free
#
#   `+x` was a register copy rather than ToNumber, so `+"2"` stayed a string
#
#   `a.length = 0` was silently dropped, so a queue Phaser had just drained was
#   still full and the next frame threw "duplicate key"
